# AutoRender Studio 1.2.6

Esta atualização reorganiza **Configurações** em quatro abas: **Caminhos**, **Fotos**, **Produção** e **Atualizações**.

Na aba **Fotos**, use **+ Adicionar ponto** para criar uma linha para cada segundo central desejado. Cada linha mostra a prévia dos três segundos usados (anterior, central e posterior). Use **Remover** para excluir um ponto. O número de trios por gravação acompanha automaticamente a quantidade de linhas. As configurações de fotos já salvas na 1.2.5 aparecem como linhas separadas.

Para atualizar uma instalação existente, pare o processamento, abra **Configurações > Atualizações**, selecione o ZIP 1.2.6 e carregue. O atualizador registra a versão atual para permitir a restauração. O pacote não contém preset, FFmpeg, configuração nem vídeos; esses itens permanecem na instalação existente.
